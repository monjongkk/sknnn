🗺️ เลือกด่าน

📚 คลังความรู้ภาษาไทย

ตัวละครและผู้ประพันธ์ ต้นฉบับ

  • สุนทรภู่ กวีเอกผู้แต่งนิทานคำกลอนเรื่อง “พระอภัยมณี” ยูเนสโกยกย่องเป็นบุคคลสำคัญของโลก พ.ศ. 2529
  • พระอภัยมณี ตัวเอกของเรื่อง ผู้มีปี่วิเศษ
  • สุดสาคร ลูกของพระอภัยมณีกับนางเงือก เกิดที่เกาะแก้วพิสดาร เติบโตกับพระฤๅษี แล้วออกเดินทางตามหาพ่อ
  • ม้านิลมังกร ม้าวิเศษลักษณะผสมม้ากับมังกร พาหนะคู่ใจของสุดสาคร พระฤๅษีช่วยให้จับมาได้
  • พระฤๅษี ผู้เลี้ยงดูและสอนวิชาให้สุดสาครที่เกาะแก้วพิสดาร
  • ชีเปลือย นักบวชเจ้าเล่ห์ ผู้หลอกชิงม้านิลมังกรและไม้เท้าวิเศษของสุดสาคร

คำศัพท์ที่ควรรู้

  • สาคร = ทะเล   นิล = สีดำ   วิเศษ = พิเศษเหนือธรรมดา
  • ผจญ = เผชิญหน้า ต่อสู้กับสิ่งที่ยากหรืออันตราย   มหัศจรรย์ = น่าอัศจรรย์เกินปกติ
  • ปริศนา = เรื่องลึกลับที่ต้องคิดหาคำตอบ   คู่ใจ = ผู้ที่สนิทและไว้ใจกันมาก
  • ปัญญา = ความรู้ความเข้าใจและความฉลาด

เทคนิคการอ่านจับใจความ

  • ถามตัวเองว่า ใคร ทำอะไร ที่ไหน เมื่อไร เพราะอะไร
  • เจอคำยาก ให้เดาจากประโยครอบข้าง แล้วตรวจกับพจนานุกรม

เส้นเรื่องของสุดสาครตามต้นฉบับ ต้นฉบับ

  1. พระอภัยมณีหนีนางผีเสื้อสมุทรได้ด้วยความช่วยเหลือของนางเงือก
  2. สุดสาครเกิดที่เกาะแก้วพิสดาร เติบโตกับพระฤๅษี และไม่เคยพบหน้าพ่อ
  3. พระฤๅษีสอนวิชา และช่วยให้สุดสาครจับม้านิลมังกรมาเป็นพาหนะคู่ใจ
  4. อายุราว 3 ปี สุดสาครออกตามหาพ่อ ต่อสู้กับผีและสัตว์ประหลาดระหว่างทาง
  5. สุดสาครพบชีเปลือย ถูกหลอกชิงม้านิลมังกรและไม้เท้าวิเศษ แล้วถูกผลักตกหน้าผา
  6. ม้านิลมังกรสลัดชีเปลือยแล้วกลับมาหาเจ้านาย พระฤๅษีมาช่วยสุดสาคร และสอนว่าอย่าไว้ใจมนุษย์ง่าย ๆ
  7. สุดสาครไปเปิดโปงความโกหกของชีเปลือยที่เมืองหนึ่ง เจ้าเมืองเอ็นดูและรับเป็นบุตรบุญธรรม
  8. ต่อมาสุดสาครออกตามหาพ่ออีกครั้ง และได้พบพระอภัยมณีในที่สุด

ส่วนที่เกมสร้างเพิ่ม เกม

  • ด่านชายหาด ป่ามหัศจรรย์ ถ้ำแห่งปริศนา และเกาะแห่งปัญญา พร้อมตัวละครช่วย เช่น ลุงนกนางนวล น้องกระต่ายป่า จิ้งจกถ้ำ ปราชญ์ผู้เฝ้าเกาะ
  • ฉากตามหาและจับม้านิลมังกร (ป้ายคำใบ้ เลือกวิธีเข้าหา ตอบคำถาม) ในต้นฉบับพระฤๅษีเป็นผู้ช่วยสุดสาครจับม้า
  • ม้านิลมังกรพูดได้ในบทสนทนาของเกม
  • ดาว เหรียญ หัวใจ ประตูปริศนา กุญแจทอง หีบสมบัติ และแบบทดสอบ
  • ฉากชีเปลือยแย่งม้าเป็นการย่อและปรับจากต้นฉบับให้เป็นฉากสั้นในเกม
  • ด่านเสียงปี่นำทางสู่พ่อ และฉากที่สุดสาครพบพระอภัยมณี เรียบเรียงบทพูดใหม่ให้เข้าใจง่าย (ในต้นฉบับ สุดสาครได้พบพ่อในที่สุด)
  • ฉากพระฤๅษีมาช่วยสุดสาครที่ก้นเหวและเรียกม้านิลมังกรกลับมา เรียบเรียงใหม่จากเหตุการณ์ในต้นฉบับที่ม้านิลมังกรสลัดชีเปลือยแล้วกลับมาหาเจ้านาย

หมายเหตุ: คำพูดของตัวละครเรียบเรียงใหม่ให้เข้าใจง่าย ส่วนเหตุการณ์ที่ติดป้ายสีน้ำเงินอ้างอิงจากต้นฉบับ สรุปจากแหล่งข้อมูลวิชาการ เช่น GotoKnow และ Wikipedia ควรตรวจสอบกับฉบับของสุนทรภู่อีกครั้งเพราะรายละเอียดอาจต่างกันตามฉบับ
